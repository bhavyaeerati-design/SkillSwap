# SkillSwap — Student Skill Exchange

## About the Project

SkillSwap is a Java Swing desktop application that helps students exchange skills. Students can list the skills they can teach and the skills they want to learn, making it easier to connect and learn from one another.

## Features

- Add student skill-exchange listings.
- Search listings by student name or skills.
- View available listings in a simple graphical interface.
- Remove listings when they are no longer needed.
- Save listings locally so they remain available after restarting the application.

## Technologies Used

- Java
- Java Swing
- ArrayList
- File Handling
- Event Handling

## Project Structure

- `SkillSwap.java` — Main Java source code and application interface.
- `skills.txt` — Local file used to store sample skill-exchange listings.
- `.gitignore` — Excludes compiled Java class files from Git.

## How to Run

1. Install the Java Development Kit (JDK).
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Compile the program:

   ```bash
   javac SkillSwap.java
   ```

5. Run the application:

   ```bash
   java SkillSwap
   ```

## Purpose

This project demonstrates Java object-oriented programming, graphical user interface development, event handling, collections, and file handling.
